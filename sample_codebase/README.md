# Standards Validation Sample Codebase

This repository is intentionally small and contains both non-compliant and compliant C++ examples. Use it with `samples/coding_standards_strict.pdf` and review the generated `standards_report.md`.

The `src/violations.cpp` file is designed to trigger naming, documentation, complexity, dynamic-memory, exception, RTTI, recursion, goto, and unbounded-loop checks. `src/compliant.cpp` provides a comparison implementation.
